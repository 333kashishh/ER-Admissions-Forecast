# ER Daily Patient Admissions Forecasting

**Predictive Analytics (CSE3141) — Mini Project**
Kashish Gupta · Reg. No. 2427030366 · Section A

## Objective
Forecast the number of Emergency Room admissions per day so hospital administrators can plan doctor and nurse staffing, especially for surges caused by poor environmental conditions.

| | Variable | Type |
|---|---|---|
| **Target (Y)** | `er_admissions` — patients admitted per day | Count |
| **Predictors (X)** | `weather_alert` — No Alert / Heatwave / Coldwave | Categorical |
| | `day_of_week` — Monday … Sunday | Categorical |
| | `aqi` — Air Quality Index (0–500) | Numeric |
| | `flu_season` — Yes / No | Binary |

## Dataset
`data/er_admissions.csv` — 1,096 daily records (2023-01-01 to 2025-12-31), generated by `generate_data.py`.
Real patient admission records are confidential, so the data is synthetic, built to follow known patterns of a Delhi-like city: worst air quality in winter, heatwaves in May–June, cold waves in Dec–Jan, flu peaks in Jan–Feb and the monsoon, busiest ER day on Monday. A few AQI values are deliberately missing to practise data cleaning.

## Method
1. Data cleaning (linear interpolation of missing AQI, encoding categories)
2. Exploratory data analysis
3. Time-based split: train on 2023–2024, test on 2025
4. Models: Multiple Linear Regression (baseline), **Negative Binomial Regression** (main), Random Forest
5. Evaluation: MAE, RMSE, R², MAPE
6. Effect sizes as % surge, and a staffing calculator using the 90th-percentile forecast

## Results (test year 2025)
| Model | MAE | RMSE | R² | MAPE |
|---|---|---|---|---|
| Linear Regression | 16.89 | 20.84 | 0.457 | 12.3% |
| **Negative Binomial** | **16.83** | **20.77** | **0.461** | 12.3% |
| Random Forest | 18.39 | 23.00 | 0.339 | 13.0% |

**Estimated surge per factor (Negative Binomial):** Heatwave +27%, Coldwave +17%, Flu season +18%, every +100 AQI +10%, Sunday −21% vs Monday.

**Staffing example:** a Monday with a cold wave, AQI 450 and flu season is expected to bring ~258 patients (plan for 307), more than double a normal clean-air Thursday (~120).
